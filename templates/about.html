About this project

NotationLearner

Chess is widely considered one of the most challenging strategic games in human history. While the rules are easy to learn, many players struggle to advance because of the game's depth and complexity. A key concept that separates casual players from serious ones is algebraic notation — the standardised system used to record and communicate moves using coordinates and symbols.

The idea behind this project came from a personal experience: a friend who could play an entire game without ever glancing at the board. Attempting to learn algebraic notation independently, I quickly realised there were no widely available tools designed specifically for practising it in the context of a real game. NotationLearner was built to fill that gap.

The application lets players compete in full chess games where every move is entered exclusively through algebraic notation — no clicking pieces on a board. A visual board is available as a teaching aid, and a built-in reference guide keeps the notation rules within reach at all times. For those who want deeper guidance, an optional hint system powered by the Stockfish chess engine suggests the best available moves. Completed games are saved to each user's account and can be replayed move-by-move through the integrated analysis interface.

The backend is built with Python and Flask, chess logic is handled by the python-chess library, and all user data and game history are stored in a MySQL relational database.
